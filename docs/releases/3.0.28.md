## 更新公告

本版本集中修复安全边界、策略防火墙运行状态、Agent 限速规则和面板更新链路，并将已在测试服务器验证的改动纳入正式构建。

### 安全与权限

- 扩展管理员权限矩阵，限制普通账号调用升级、授权、节点、隧道、策略、后台支付和批量用户管理接口。
- 新密码改用 bcrypt；旧 MD5 密码会在首次成功登录后自动迁移，无需统一重置账号。
- 授权信息、HMAC、验证码私钥和支付渠道密钥不再通过普通配置接口返回。
- CORS 默认仅允许同源请求，额外来源必须通过 `CORS_ALLOWED_ORIGINS` 明确配置。
- 新安装生成 32 字符随机 JWT 密钥，过短或空密钥会阻止后端启动。

### 策略防火墙

- 新增规则源、策略和绑定管理，可将纯 IP/CIDR 策略绑定到节点入口、节点出口或指定隧道作用域。
- Agent 使用独立的 nftables 策略表下发规则，支持应用、撤销、状态查询、漂移检测和启动恢复。
- 删除或修改策略前会先撤销节点运行态；应用失败时回滚已经写入的规则。
- 增加计划级互斥锁、孤立状态清理和有界并发恢复，避免删除与重放发生竞态。
- Mihomo Sidecar 未配置时会明确报告失败，不再把仅生成配置草稿误报为部署成功。

### Agent 与限速

- 修复 nftables 限速表达式缺少单位的问题，并按 Mbps 正确转换为 bytes/s。
- Agent 可识别并重建旧版本生成的不可解析 FLVX 自有规则表。
- 修复 nftables 域名刷新读取错误数据表的问题。

### 更新与部署

- 更新窗口现在会展示对应 GitHub Release 的更新公告，并对 Markdown 内容进行安全过滤。
- 修复 Nginx 反向代理丢失访问端口后导致同源请求被 CORS 拒绝的问题。
- 安装脚本、Nginx 配置和 GitHub Actions 文件统一使用 Linux LF 换行。
- Release 同步生成 AMD64/ARM64 Agent、校验文件、离线包、Compose 文件以及前后端多架构镜像。

### 验证

- 已完成普通用户越权、敏感信息脱敏、CORS、密码迁移和策略生命周期黑盒测试。
- 已完成后端定向测试、Agent 全量测试、前端生产构建以及 Linux ARM64 交叉编译。
- 测试服务器已验证前端访问、后端健康检查、Agent 重启恢复和策略删除闭环。

### 使用限制

- Mihomo Sidecar 仍为预览能力，目前不包含自动安装、进程托管、透明接管和健康检查；域名策略暂不建议用于生产流量。
- 升级前建议备份数据库和部署目录，并确保系统盘具有足够剩余空间。
